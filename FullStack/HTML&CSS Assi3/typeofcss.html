Demonstration of Cascading Style Sheets

This webpage demonstrates the three ways of applying CSS: Inline, Embedded, and External stylesheets.

1. External Stylesheet

The styles for this section are written in a separate style.css file.

This paragraph is styled using external CSS.

2. Embedded Stylesheet

The styles for this section are written inside the <style> tag in the HTML document.

This section uses internal or embedded CSS.

3. Inline Style

The styles for this section are applied directly to HTML elements using the style attribute.

This paragraph is styled using inline CSS.

CSS Types Summary

CSS Type Where It Is Written Example
External Separate .css file style.css
Embedded Inside <style> tag HTML <head>
Inline Inside HTML element style="color: red;"
